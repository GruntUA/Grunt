# План реалізації пропущеного функціоналу (Gap Closure: Grunt vs Frappe)

Цей документ описує етапи реалізації функцій, які зараз присутні у Frappe, але відсутні в Ґрунті, для досягнення зрілості корпоративного рівня.

---

## 1. Кастомні контролери документів (Python Classes)
**Мета:** Дозволити розробникам створювати класи Python для специфічних DocType з перевизначенням бізнес-логіки.

- [x] Створити базовий клас `Document` у `backend/grunt/core/document/base.py`.
- [x] Реалізувати механізм автоматичного завантаження (discovery) класів з директорій додатків.
- [x] Оновити `DocumentService`, щоб він використовував ці класи замість загальної реалізації, якщо вони існують.
- [x] Додати стандартні хуки-методи: `before_insert`, `after_insert`, `before_save`, `after_save`, `before_delete`.

## 2. Глобальна система хуків (App Interoperability)
**Мета:** Механізм взаємодії між різними додатками (apps).

- [x] Розширити `backend/grunt/core/hooks.py` для підтримки реєстрації через конфігураційні файли додатків.
- [ ] Додати підтримку "monkey-patching" методів та розширення схем існуючих DocTypes іншими додатками.
- [ ] Реалізувати черговість виконання хуків (priority).

## 3. Фонові завдання та Планувальник (Background Jobs & Scheduler)
**Мета:** Виконання асинхронних та регламентних робіт.

- [x] Інтегрувати **TaskIQ** або **ARQ** (асинхронні черги для Python).
- [x] Додати декоратор `@task` для маркування фонових функцій.
- [ ] Додати модуль `Scheduler` для запуску задач по Cron-виразах (наприклад, через `apscheduler`).
- [ ] Створити UI в Desk для моніторингу статусу фонових завдань.

## 4. Поштова підсистема (Email Engine)
**Мета:** Комунікація з користувачами через Email.

- [x] Реалізувати `EmailAccount` DocType для налаштування SMTP/IMAP.
- [/] Створити системний сервіс відправки листів з чергою (Email Queue).
- [ ] Додати підтримку шаблонів листів (Jinja2).
- [ ] Реалізувати автоматичне створення документів (наприклад, Support Ticket) з вхідних листів.

## 5. Інструменти управління даними (Import/Export)
**Мета:** Масове завантаження та вивантаження даних.

- [ ] Реалізувати `DataImporter` сервіс, що підтримує CSV та Excel.
- [ ] Додати мапінг колонок файлу до полів DocType.
- [ ] Реалізувати валідацію даних перед імпортом з детальним звітом про помилки.
- [ ] Додати експорт списків у Excel/PDF.

## 6. Колаборація та соціальні функції
**Мета:** Покращення взаємодії користувачів.

- [ ] Додати `Comment` DocType для обговорень під кожним документом.
- [ ] Реалізувати систему призначень (`Assignment`) та сповіщень.
- [ ] Додати тегування документів.
- [ ] Реалізувати `SharedWith` для гнучкого управління доступом до окремих записів.
