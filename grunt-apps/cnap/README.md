# ЦНАП — Реєстр звернень громадян

Demo-додаток на платформі Ґрунт для центрів надання адміністративних послуг.

## Встановлення

```bash
# Сервер має бути запущений
grunt serve

# В іншому терміналі
python grunt-apps/cnap/install.py
```

## DocTypes

- **Applicant** — Заявник (фізична/юридична особа)
- **ServiceCategory** — Категорія послуги (довідник)
- **AdminService** — Адміністративна послуга (довідник)
- **Appeal** — Звернення громадянина (головний DocType з workflow)
- **AppealDocument** — Документ звернення (child table)

## Workflow звернення

```
Нове → В роботі → На погодженні → Виконано
                 → Відмовлено
Нове → Скасовано
```
